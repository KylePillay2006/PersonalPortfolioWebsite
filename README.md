## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic text editor or IDE (VS Code recommended)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/KylePillay2006/portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd portfolio
   ```

3. **Open the website**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx serve
     ```

4. **View in browser**
   ```
   http://localhost:8000
   ```

## ✏️ Customization Guide

### Update Personal Information

1. **Name and Title** (Line ~593-595)
   ```html
   <h1>Your Name</h1>
   <h2>Your Title</h2>
   ```

2. **About Section** (Line ~604-624)
   - Update bio text
   - Add your photo by replacing the icon

3. **Skills Section** (Line ~631-722)
   - Modify skill names and descriptions
   - Adjust progress bar percentages
   - Update repository links

4. **Projects** (Line ~728-799)
   - Add your project details
   - Include live demo and GitHub links
   - Update technology tags

5. **Contact Form** (Line ~891-904)
   - Replace FormSubmit email with yours:
     ```html
     action="https://formsubmit.co/YOUR_EMAIL@example.com"
     ```

6. **Social Links** (Line ~907-920)
   - Update LinkedIn, GitHub, YouTube, and Email URLs

### Add Your Photos

Replace icon placeholders with actual images:

```html
<!-- Profile Image -->
<div class="profile-image">
    <img src="assets/images/profile.jpg" alt="Kyle Pillay">
</div>

<!-- Project Images -->
<div class="project-image">
    <img src="assets/images/project1.jpg" alt="Project Name">
</div>
```

## 🌐 Deployment

### GitHub Pages (Free)

1. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Initial portfolio commit"
   git push origin main
   ```

2. **Enable GitHub Pages**
   - Go to repository Settings
   - Navigate to Pages section
   - Select `main` branch
   - Save and wait for deployment

3. **Access your site**
   ```
   https://yourusername.github.io/repository-name
   ```
